Supplements are one product/use case, not an approved top-level economic taxonomy. The following domains overlap in the world; work ownership below is deliberately more specific.

### Disputed ownership handling

Consumers submit a seam request instead of editing another worker's definitions. Each conflict record contains id, competing representations/owners, baseline rule, affected CQ/query/failure, exact source locators, smallest failing fixture, alternatives, migration consequences, proposed ruling and status. Fable assigns one resolver and obtains the affected owners' responses. A claim about ownership cannot be settled by majority vote or similar naming. Unresolved conflicts are deferred with preserved public interfaces or block the dependent output; never emit two types representing the same canonical identity.

Specific mandatory seam checks: ChemicalSubstance versus Compound; ChemicalForm versus IngredientMaterial versus dosage form; Source versus Document versus Publication versus Episode; Claim identity versus Assertion occurrence; `StudyIntervention` node versus existing same-named union (accepted projection name `ArmIntervention`); ProtocolEdition versus study ProtocolVersion; public Observation versus DiagnosticResult contract versus private PersonalMeasurement; asserted `assertionUid` versus derived `projectionOfAssertionUid`; specification ownership across W04/W11/W12; media region locator versus asset annotation; Source Intelligence research ownership versus provenance canonical ownership. Catalog uses `HAS_PROTOCOL_STEP` where round/live prose uses `HAS_STEP`: record and resolve that naming/projection seam explicitly.

## 5. Frozen shared contract

Preserve the intended kernel unless a primary source plus concrete failing case warrants an explicit kernel-change proposal:

- Exactly one high-order archetype per shared node: Entity (persistent identity); VersionedState (bounded state); Occurrence (something happened); InformationArtifact (representation/record); Assertion (attributable proposition); EvidenceAssessment (adjudicated evaluation). Multiple domain labels do not imply multiple archetypes. A GraphQL `Entity` interface is not automatically a stored archetype label.
- Freeze `hu:<type>:<opaque-stable-id>`, catalog token registry, id/uid mapping and aliases, external identifier namespace/issuer/version, redirect behavior and deduplication before fragments. New tokens require registry admission. Never use display names or market URLs as canonical identity.
- Authority remains with Assertion. Assertion has at most one asserter; ClaimOccurrence has exactly one asserter and container. Claim proposition identity has no truth value. Literal/object endpoints, predicate vocabulary, speech act, basis, polarity and cardinality are shared contracts.
- Status expresses capture fidelity, not truth. CAPTURE_FIDELITY and SUPPORT adjudications are distinct. Extraction, resolution, reliability, strength, applicability and decision confidence have separate methods/versions.
- Structural/asserted/derived edge class is mandatory. Asserted projections cite exactly one Assertion and carry the asserted-edge profile. Derived projections retain input assertion(s)/rule; no derived edge is sole history or a forbidden-inference workaround.
- Bitemporal valid/recorded clocks, half-open episodes, per-bound precision/basis, null unknown bounds, publication/observation/retrieval/effective distinctions, service-assigned recorded time, immutable valid time, correction versus fact-ending and late-fact behavior are frozen. No backdating knowledge.
- Preserve unknown, unmeasured, notReported, belowDetection, absent and false as distinct meanings. Reuse actual catalog enums/fields; no unreviewed universal enum that collapses them.
- Jurisdiction, dose/quantity/mass/serving basis, formulation versions, population/context of use and measured versus inferred mechanisms must survive extraction and queries. Marketed is not approved; identification is not evidence applicability.
- Shared graph contains zero private-personal nodes, properties, relationships or private uid values. Public research/protocol descriptions remain separate from private personal health/execution/decision records. The latter remain in a separate transactional store referenced by uid/viewpoint.
- Preserve all catalog forbidden implications and validators. Examples: advising/sponsorship/financial interest do not imply endorsement; supplying an investigational product does not establish ingredient supplier; registration/clearance is not approval; hosting/fulfillment is not selling; practice report is not recommendation; no reported adverse events is not no events; same substance is not current-product evidence.
- Shared enum definitions, relationship-property names/direction/cardinality, source/hash/selector conventions, access tier closure and validation naming are one versioned contract. Any exception needs a conflict record, failing case and synthesis ruling.

## 6. Standard worker output contract

Future run path: `docs/schema/ontology-lab/final-proposal-team/<run-id>/workers/Wxx/`. Each worker writes only its assigned directory, imports frozen shared definitions and delivers:

1. **Domain recommendation:** boundaries/subdomains, actual baseline names and canonical modules; keep/refine/merge/split/seam/defer dispositions; identity versus state/artifact/occurrence; alternative designs and smallest recommended model. No generic industry survey.
2. **CQ coverage matrix:** existing ids/priority/answerability; new ids explicitly candidate with rationale; example answer → distinction → evidence requirement → proposed node/property/edge/edge property → query → prevented failure. Every proposed element maps to a CQ, invariant, ingestion failure or justified interoperability requirement. Unused elements stay candidates.
3. **Source manifest and case packet:** primary URL/id, title/source kind, publisher/asserter/authority scope, publication/observation/retrieval times, exact page/field/quote/timecode/region, capture method/completeness/hash basis, excerpt/file reference, restrictions, cannot-establish statement. Distinguish newly retrieved records from inherited repository citations and synthetic fixtures.
4. **Model cards and proposed SDL fragment:** actual full owned type definitions (not only extend blocks), properties with meaning/type/null/units/value-state/privacy, edge domain/range/direction/cardinality/class and edge properties, temporal/versioning rules, derived input/rule, identity keys/aliases, enum ownership and source references. Import other owners' identities rather than redefining them. A fragment is a recommendation, not yet an executable merged schema.
5. **Decision/objection and seam ledger:** evidence-linked alternatives, accepted-for-proposal versus unresolved, kernel-change requests, unresolved dependencies/owner and concrete closure criteria. No fabricated consensus.
6. **Fixtures and queries:** realistic public or synthetic positive, negative and minimal-pair cases; expected rows/values/error or violation id, not just query syntax; temporal correction/late arrival, identity collision, missing facts and access leakage. Distinguish run/EXPLAIN/parser-only/not-run.
7. **Operations recommendation:** uniqueness/index needs, retrieval pattern justification, application validation and transaction/concurrency requirements; target capability/minor/edition conditions; idempotence, lifecycle, migration/compatibility and ingestion/normalization overhead. No application runtime implementation is required from a modeling worker.
8. **Completion report:** source/tool availability, research gaps, unresolved seams and confidence dimensions, artifact paths/digests and review status. A blocked authoritative record is a qualified answer, not invented retrieval.

### Future research tools and fallbacks

Inventory actual tools/credentials before using them. Preferred discovery/capture: Firecrawl and Tavily; scientific records: PubMed and ClinicalTrials.gov; authoritative trials/results/papers/full texts/labels/regulatory records/filings and company/investor pages for their own statements. Search to resolve a modeling question, such as whether a dose basis or version identifier is publicly reported, not to accumulate unrelated papers. Company pages establish what a company says, not agency approval or independently verified capability.

PubMed fallback: NLM E-utilities or official record/PMC where available; ClinicalTrials.gov fallback: official API v2/record, with registry history explicitly unavailable if not retrieved. Firecrawl/Tavily fallback: an available authorized web tool or direct official record capture. Transcript fallback: publisher transcript/captions with version/timeline caveats; no claim of audio verification from text alone. Never invent a fetch, locator, full text, historical registry version or tool result. Do not install paid services, expose credentials, bypass access controls or treat blocked retrieval as absence.
