# 02 Ownership registry (v0 at contract freeze; Fable updates only through recorded decisions)

Rule: every node type, relationship type, relationship-property type, enum and union has exactly one **sole file writer** (the worker whose `sdl-fragment.graphql` defines it). The **canonical catalog module** is unchanged by research ownership. Consumers reference by name and file seam requests. Baseline canonical owners come from `docs/schema/ontology-lab/modules.yaml`; live types owned by no module are seams and are assigned a research owner here.

Legend: W = sole file writer; module = canonical catalog module; "live" = defined in `current_biotech_schema.graphql`; "cat" = defined in catalog 0.2.0; "new" = proposed in this run (must be candidate until a CQ/failure justifies it).
