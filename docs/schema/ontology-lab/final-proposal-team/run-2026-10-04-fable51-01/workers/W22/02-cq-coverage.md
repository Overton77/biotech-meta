# W22 CQ coverage matrix

No existing competency question names media assets. Six questions are proposed here as **candidates** (`CQ-MD-Cnn`, area code MD = media). Each answers a display, rights or lineage need that the handoff (section 6, "Mandatory media cases") and the media/protocol review ("candidate display CQ") require. Existing CQs are mapped where a media path is part of the answer. Priority and answerability use the scheme in `competency-questions.md` section 1.1 and 1.2.

Rationale for the candidates: the handoff makes asset selection, rights, lineage and depiction-versus-evidence **mandatory** media cases ("add asset selection/rights/concept coverage CQs before promotion"). The media/protocol review lists "candidate display CQ plus CQ-PV-01/06". None of these can be expressed through existing CQ ids without stretching them. CQ-MD-C04 and CQ-MD-C05 are proposed as Foundational because lineage and the evidence/illustration distinction cannot be reconstructed after ingestion. A crop without a recorded region, or an asset without an ORIGINAL hash, is unrecoverable.
