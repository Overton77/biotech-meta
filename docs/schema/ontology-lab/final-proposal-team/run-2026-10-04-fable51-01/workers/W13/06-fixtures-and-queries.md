# W13 fixtures and queries

All fixtures were **run** in this session on embedded **Neo4j 5.26.31 Community**. The DBMS reported `Neo4j Kernel 5.26.31 community`. The run used the in-process harness in `validation/harness` (`EmbeddedNeo4j.java`, `run-cypher.mjs`) on a fresh database directory per scenario. The JSON outputs are in `fixtures/run-results/`. The fixture text is generated by `fixtures/generate_w13_fixtures.py`, and the generated `.cypher` files are the deliverable.

**Conventions:**

- Statements are separated by `;`.
- Every statement binds its own nodes by uid with `MATCH … {uid: …}`; no variable crosses `;`.
- Nodes carry the primary label and the archetype label, plus `Organization` and `RegulatoryStatus` parent labels where applicable.
- Uids use registered tokens. The exceptions are `reg-pathway-version`, `reg-step`, `regulatory-inspection` (W13-SR-04) and `mixture` (W02, W13-SR-11).
- Snapshots use `contentHashBasis: 'SYNTHETIC_FIXTURE'`. Locator `quoteHash` is a real sha256 over NFC-WS1-normalized quoted text.
- Recorded time is fixed: 2026-10-04T02:00Z for this session's ingestion. 2024-07-10 and 2025-04-02 are used for a synthetic replay of earlier ingestion, with synthetic snapshots retrieved before each.

## GraphQL-layer checks (run)

`fixtures/run-results/gql-roundtrip.mjs` used the fragment plus `run-results/build-stubs.graphql`, `@neo4j/graphql` 7.6.3, against scenario A.

**Build:**

- `Neo4jGraphQL.getSchema()` builds: 1,195 generated types, 51 queries, 60 mutations.
- The fragment alone parses with graphql-js.

**Reads that worked:**

- `regulatoryStatuses(where: {statusKind: {eq: APPROVAL}})` returns only REZDIFFRA's DrugApproval node, so the specialization labels are read through the parent type.
- `drugApprovals.approvalFor` → Product.
- `orphanDesignations.designationFor` → MaterialMixture.
- `regulatoryPathways.versionsConnection.edges.properties` resolves.
- `regulatoryStatuses.statusOfConnection` over the union (with AssertedEdgeProperties) resolves both LDT episodes to `AssayVersion`.
- `legacyHeldByConnection` returns the DerivedEdgeProperties.

**Writes:**

- A create mutation that sets the derived `legalBasisCitation` is rejected ("not defined by type RegulatoryPathwayCreateInput"). `@settable(false)` therefore removes it from the input type.

**Limitation found:**

- Any selection of a DateTime field fails with `Unknown function 'apoc.date.convertFormat'`. The embedded Community harness has no APOC (W13-SR-16).
