## 3. Application validation and transactions (Community cannot enforce these)

1. **Event write unit** (one transaction): create/merge the Event by `uid`; create the EVENT_* Assertion(s) with `HAS_SUBJECT`, `ASSERTED_BY`, `SUPPORTED_BY` locator; create projection edges (`INVOLVES`, `EVENT_ABOUT`, `DOCUMENTED_BY_RECORD`) with `assertionUid` and `recordedFrom = datetime.transaction()`; recompute the Event materialization (`event-time-materialization-v1`, `announced-at-v1`) and `eventStatus`; run W18-V04/V07/V09/V13 scoped to the event before commit; abort on any row.
2. **Causal write unit**: the CAUSED_BY assertion and its edge in one transaction; copy `basisKind`, `assertionBasis`, `speechAct` from the assertion; reject when the assertion has no `basisKind`, polarity ≠ POSITIVE, or subject/object ≠ effect/cause (W18-V01 scoped). No service may write CAUSED_BY from a derivation job.
3. **Derived edges** (`FOLLOWED_BY`, `REPORTED_IN`, `SUPPORTED_BY_CHUNK`): regenerated by a job after any change to an event's time or support assertions: delete-and-recreate per event in one transaction (they are never the only history); W18-V08 after regeneration.
4. **Arcs and impact assessments**: created once with all structural edges in one transaction (`@settable(onUpdate: false)` on members in GraphQL); revision = new node + `SUPERSEDES` + write-once `recordedTo` on the old node in the same transaction; W18-V03/V12 before commit.
5. **Concurrency.** Two ingesters reporting the same occurrence can create two Events: uniqueness on `uid` does not prevent semantic duplicates. Writers resolve by (subject, eventType, jurisdiction, record uid or day) inside the transaction with `MERGE` on a deterministic uid when a record exists (`hu:event:<record-derived-id>`), otherwise create and leave an `EquivalenceAssessment` (W00) for review. Materialization recomputation relies on the node write lock Neo4j takes on the Event at the first `SET` in the transaction; two concurrent recomputations serialize.
6. **Privacy.** Before any `SPEAKS_AT`/`ATTENDS`/`INVOLVES` write to a Person, check `privacyClass = 'PUBLIC'` and a public source (W18-V11); communities never get member edges.

- `@neo4j/graphql` 7.6.3 returns every `DateTime` field through `apoc.date.convertFormat`; **APOC Core is a runtime prerequisite** for reading Event/Arc/Assessment times through GraphQL (observed: error without APOC, success with APOC Core 5.26.31; agrees with W00's D-W00-17).
- `Conference.startDate/endDate` as GraphQL `Date` round-tripped (`"2026-01-12"`) from Cypher `date()` values.
- Relationship property uniqueness constraints ran on Community 5.26.31; existence/type constraints remain Enterprise-only and unverified.
- Merged build with all present fragments + stubs: 32 s, 38,911 generated types (heap default). Planning cost of union-heavy queries was not measured for W18's unions (≤ 15 members).

## 5. Idempotence, lifecycle, migration, ingestion overhead

- Fixtures use `MERGE` by `uid` (nodes) and `relationshipUid` (asserted edges); reloading a fixture adds no nodes. Structural edges without `relationshipUid` (`HAS_EVENT`, `ARC_INCLUDES_EVENT`, `HAS_SUBJECT` …) `MERGE` on endpoints.
- Migration (see `migration-map.yaml`): relabel live nodes with archetype labels; backfill `uid`; convert every live event date and edge into a MIGRATION assertion (`extractionMethod: live-edge-migration-v1`, status EXTRACTED, bases UNKNOWN unless provable); move `impactLevel` to `EventImpactAssessment {methodVersion: legacy-import-v0}`; delete `eventPhase`; regenerate `FOLLOWED_BY`; retype `Conference.startDate/endDate` with the venue time zone. Legacy CAUSED_BY edges without basis stay visible to W18-V01 and are excluded from answers until a basis is captured.
- Overhead: an event costs roughly 1 node + (2–4) assertions + (3–6) projection edges + derived edges; fixture 01 (6 events, 9 sources) is 220 statements and 74 nodes including provenance and actors. The overhead is the price of answering "as recorded at R" and of keeping company and regulator dates apart.
