| Does an Amazon page state host, seller and fulfiller separately? | Yes (S1, S2, S4). "Ships from" and "Sold by" are separate fields; the merchant link carries the seller id and `isAmazonFulfilled`. In every case captured, the host is Amazon; the fulfiller is Amazon or the seller; the seller is Amazon or a third party. No captured page showed all three as three different parties (host Amazon, seller X, fulfiller Y); B000QSNYGI shows every two-way split. | Three separate asserted edges (HOSTS_LISTING, SELLER_OF_RECORD_FOR, FULFILLS_OFFER); the same organization may hold several roles, each with its own assertion. |
| Does a marketplace merge several sellers under one listing? | Yes: B000QSNYGI, one ASIN, four offers, four sellers, three fulfillers (S4). | One MerchantListing, several Offers (catalog note confirmed). |
| Does a DTC store expose subscription terms as data? | Yes: Shopify `selling_plan_groups` with plan ids and intervals (S6), administered by an app (`ordergroove-subscribe-and-save`). The plan JSON carries **no** price adjustment while the rendered page shows "Save 20%" (S7). | SubscriptionPlan holds plan id, interval, provider and the plan's own declared adjustment; the price is a PriceObservation; JSON and page prices are two observations. |
| Do listings identify themselves at variant level? | Shopify: each size is a variant with its own id, barcode and URL parameter; Amazon: each size is its own ASIN (B07TK5K5TQ 30-count, B07Y2ZGM48 two-bottle, B07Y8S65SQ 180). | MerchantListing = the most specific merchant catalog entry; product page / parent ASIN is `parentListingRef`. |
| Are multi-unit "sizes" packages or bundles? | The DTC "180" is SKU `CTNUS3006090010-KIT` (a kit of the 90-count SKU, count not stated); Amazon "Two-bottle supply"; brand "30/30" kits. | Bundle + BundleComponent with `quantityStatus` NOT_REPORTED when the count is not stated; LISTING_FOR may target a Bundle. |
