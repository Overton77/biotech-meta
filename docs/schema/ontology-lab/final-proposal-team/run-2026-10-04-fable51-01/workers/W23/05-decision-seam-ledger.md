## Objections raised and answered (challenger role on own packet)

| Objection | Answer |
|---|---|
| "An INTERNAL AnswerRecord makes public answers irreproducible." | The reproducibility allow-list is public (Q-AR-5); only lineage is withheld. |
| "OWNER_PRIVATE in a shared enum is a private value." | It names a tier; no private data is encoded. Offered alternative recorded (D-W23-04). |
| "Cypher's `<> 'INTERNAL'` already fails closed on null." | True in Cypher (Q-FO-2), false in application code and in Neo4j DENY rules (S-2); the allow-list is the only form that is safe in all three. |
| "V-W23-04's property list will drift." | It is generated from private-store-interface §9; names shared types use are excluded on purpose (checked 2026-10-04), so false positives are avoided; drift is caught when a new private field is added to the contract. |
| "The public-person rule may block legitimate legacy RECORDS edges." | It reports them (no deletion); migration attaches the missing assertion or retires the edge. |
